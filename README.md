# Recall V4 — Compreensão + Produção ativa

## Novidades
- `👁 Compreensão`: idioma-alvo → português.
- `🗣 Produção`: português → idioma-alvo.
- `🧠 Smart Mix`: escolhe automaticamente o sentido.
- Cada direção tem intervalo, facilidade, revisões e lapsos independentes.
- English Smart Mix tende a ~60% de produção depois que ela é liberada.
- Deutsch Smart Mix começa com ~20% de produção; produção só entra após maior familiaridade.
- Produção não toca áudio antes de você responder, para não revelar a frase.
- Ao virar um card de produção, o áudio da resposta pode tocar automaticamente.
- Corrige o comportamento de `Não lembrei`: o card realmente espera 10 minutos antes de voltar.
- Migração automática da V3 e da V1, preservando o progresso existente.
- GitHub continua usando um único item por frase; não duplique frases invertidas.
